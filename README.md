###  Show HN: RunAIToolkit – Free, Client-Side AI Utilities for Creators & Developers

Hey everyone,

I built **[RunAIToolkit](https://runaitoolkit.com)**—a lightweight, privacy-first web platform designed to streamline daily AI workflows for developers, prompt engineers, and digital creators.

Most online utility sites are bloated with server-side latency, aggressive paywalls, or privacy concerns regarding input data. **RunAIToolkit** runs 100% inside your browser. Your text, image files, and prompt data never touch an external server—zero API calls, zero server overhead, and lightning-fast local processing.

---

### 🛠️ What’s inside the toolkit?

* **AI Token & API Cost Estimator**
Quickly calculate exact token counts and estimate API usage costs across major LLM models (including GPT-4o, Claude 3.5, and DeepSeek). Essential for budgeting before running massive prompt batch processing or agentic workflows.
* **Prompt & Markdown Cleaner**
Instantly strip unwanted formatting, system artifacts, invisible characters, and noisy markdown tags from raw LLM outputs. Ensures clean, standardized text ready for production code bases, CMS platforms, or secondary prompt chaining.
* **Midjourney & Flux Grid Splitter**
Easily split 2x2 image grids generated by Midjourney, Flux, or Stable Diffusion into high-resolution, individual images directly via in-browser HTML5 Canvas. Zero quality loss and no uploading wait times.

### ⚡ Technical Stack & Highlights

* **Tech Stack:** Next.js (App Router), Tailwind CSS, Shadcn/ui.
* **Deployment:** GitHub + Cloudflare Pages (Static Export via Anycast Edge CDN).
* **Privacy-First Architecture:** All operations run locally using Client-Side JavaScript and Web Workers.
* **Responsive & Ad-Friendly Layout:** Minimalist UI with zero layout shifts (CLS-safe) for a seamless reading and working experience.
